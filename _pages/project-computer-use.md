<p class="eyebrow">Ongoing project · Visual grounding & GUI interaction</p><p class="intro">Connecting instructions, visual state, and actions in multi-step segmentation workflows.</p><h2>Current work</h2><p>I am developing a GPT-6 Astra computer-use agent for video-assisted segmentation in ITK-SNAP. The project explores how an agent can use interface observations to guide interactions in an annotation application.</p><h2>Workflow under development</h2><ol class="steps"><li><strong>Observe</strong><span>Inspect the interface and current segmentation state.</span></li><li><strong>Plan</strong><span>Choose the next interaction in the annotation workflow.</span></li><li><strong>Act</strong><span>Execute GUI interactions in ITK-SNAP.</span></li><li><strong>Check</strong><span>Inspect the resulting state and progress toward task completion.</span></li></ol><p>This is ongoing development. The observation–action loop is a design focus; no benchmarked task-completion rate is reported here.</p>
